# 🍰 CuteCake Studio

Landing page responsiva para uma confeitaria fictícia, desenvolvida com HTML, CSS e JavaScript modular, apresentando produtos, categorias, carrossel de bolos e catálogo completo.

## ✨ Sobre o projeto

O CuteCake Studio é uma interface de confeitaria com uma identidade visual delicada e moderna, utilizando tons de roxo, rosa e lilás.

## 🖥️ Funcionalidade:

- Navegação responsiva;
- Hero section com destaque para os bolos;
- Categorias de produtos;
- Carrossel de produtos;
- Filtro por categoria;
- Catálogo completo;
- Botão para expandir/recolher o catálogo;
- Menu mobile;
- Dados dos produtos separados em JSON;
- Componentização do JavaScript com módulos ES6.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- JSON
- Font Awesome
- Google Fonts
- Fetch API
- ES Modules

## 🚀 Como executar
Clone este repositório:     
``
git clone https://github.com/Shillue/cutecake-studio-landing-page.git
``   
Acesse a pasta do projeto:       
``
cd cutecake-studio-landing-page
``    
Como o projeto utiliza Fetch API para carregar os produtos do arquivo JSON, recomenda-se executá-lo através de um servidor local.       
Depois, abra o projeto no navegador através do servidor local.
